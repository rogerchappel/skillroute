# Support

`skillroute` is an early local-first CLI. The supported surface is the current `main` branch, the documented `skillroute plan` command, and the exported route planner helpers.

## Before Filing an Issue

Run:

```sh
npm run release:check
```

Include:

- The command you ran.
- A minimal redacted catalog and task prompt.
- The expected route and the route that was produced.
- Your Node.js version.

Please redact private skill names, proprietary prompts, credentials, and approval-policy details before sharing examples publicly.

## Optional Feedback

If you have used `skillroute`, you can share feedback through a GitHub issue. State whether the report describes a firsthand use or a suggestion; do not present a hypothetical scenario as observed user experience. Include only the command, a minimal redacted catalog and task prompt, and the expected and actual route when relevant. Do not include private skill names, proprietary prompts, credentials, or approval-policy details. Sharing is optional; no telemetry or automatic feedback collection is performed.

Feedback status is tracked in [`docs/TASKS.md`](docs/TASKS.md). A task is marked complete only when a maintainer records a verifiable, publicly shareable feedback source there; until then, feedback remains uncollected or unverified. Do not add private messages or identifying information to the repository. A lack of recorded evidence is not evidence of user satisfaction or dissatisfaction.
